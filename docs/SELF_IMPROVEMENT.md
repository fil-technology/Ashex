# Self Improvement

This pass lays down the auditable storage needed for the self-improvement loop:

- durable memory files
- lessons files under `.learnings/`
- generated skill drafts
- quarantined portable skills
- KB explorations and reports

The intended loop is:

```text
observe outcome -> record lesson -> propose memory/skill/KB update -> audit -> promote or leave quarantined
```

Automatic amendment evaluation and rollback are not live yet. Generated skills remain disabled until reviewed.
