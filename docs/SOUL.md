# SOUL.md

`SOUL.md` is the durable persona file for ASHEX. It lives under the selected ASHEX storage root, usually `.ashex/SOUL.md` for a project-local run or a user-provided `--storage` path.

Commands:

```bash
ashex soul show
ashex soul edit
```

Keep this file about identity and interaction style. Project architecture, commands, ports, and workflows belong in `AGENTS.md` or `.ashex.md`.
